# 美国签证预约监控（US Visa Slot Watcher）

一个 Chrome 插件：按你设定的时间间隔，自动检查 **usvisascheduling.com** 上有没有你日期范围内的签证面谈空位，并把每次的检查结果推送到你的手机。

- 自动打开预约网站、登录、进入日历、读取空位
- 每一轮检查都推送一条到手机：有空位、没空位（附上所有可选日期），或者失败原因
- 网站排队、限流、维护时自动等待或重试，遇到访问受限立即停止
- 完整的中文操作记录，每一步做了什么都查得到
- 可选：自动预约最早的符合条件的空位（默认关闭）

---

## ⚠️ 使用前必读

**请先认真读完这一节。使用本插件即表示你理解并自行承担以下风险。**

- **预约网站的使用条款禁止自动访问。** 开启自动检查后，插件会在你不操作的情况下访问网站，这违反了网站条款。网站会主动识别插件和自动化行为，**你的账号可能被限制访问，通过自动化手段获得的预约也可能被取消。**
- **不保证能约到。** 插件只负责发现空位并提醒你。
- **自动登录会以明文保存你的密码和安全问题答案**，存在浏览器本地的配置文件里。任何能读取你电脑文件的程序都能看到。
- **自动预约一提交就生效，不能撤回。** 预约网站限制改约次数，错过预约还要重新交费。除非你完全清楚自己在做什么，否则不要打开。
- 检查间隔请**尽量设长**（建议 10 分钟以上）。间隔越短，越容易触发人机验证、限流甚至封禁。
- 插件不会、也不应该被用来绕过人机验证。遇到验证时，它会暂停并等你手动完成。

本项目与美国国务院、预约网站及其运营方没有任何关系，仅供学习交流。

## 安装

1. 在本页面右侧的 **Releases** 里下载最新版的 zip 文件，解压到一个固定的文件夹（之后不要删除或移动它）。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择刚才解压出的文件夹（里面有 `manifest.json` 的那一层）。
5. 点浏览器右上角的拼图图标，把"美国签证预约监控"固定到工具栏上，方便打开。

**更新版本：** 下载新版 zip，解压覆盖原来的文件夹，然后在 `chrome://extensions` 里点这个插件的刷新按钮。

## 设置

点插件图标 → 弹窗底部的 **设置**。

### 1. 关注的日期
- **能接受的最早日期 / 最晚日期**：只有落在这个范围内的空位才算"符合条件"。留空表示从今天到六个月后。
- **领馆（可选）**：填领馆名字，比如 `GUANGZHOU` 或 `广州`。你的账号下只有一个领馆时可以不填，插件会自动选择。

### 2. 推送到手机（强烈建议设置）
1. 在手机上安装免费的 **ntfy** App（iPhone 在 App Store，安卓在 Google Play 或 F-Droid）。
2. 在 App 里点 **+** 订阅一个主题（topic）。**主题名请用一长串随机字母数字**，比如 `visa-k3f9x2p7q8m1`。主题是公开的，任何知道名字的人都能看到你的推送，所以千万别用自己的名字或简单的词。
3. 把同一个主题名填进插件设置的 **ntfy.sh 主题**，点 **发送测试推送**，手机收到就说明设置成功。

之后每一轮检查都会推一条：

| 推送标题 | 含义 |
|---|---|
| **发现空位，快去预约！** | 出现了新的符合条件的空位（最高优先级，点开直接打开预约网站） |
| 检查完成：空位仍在 | 之前推过的空位还在 |
| 检查完成：没有符合的空位 | 正常检查完成，附上日历上所有可选日期 |
| 检查失败：…… | 这一轮没成功，后面写着原因（需要登录、网站维护、页面打不开等） |
| 预约网站拒绝访问 | 出现访问受限，自动检查已关闭 |
| 预约已提交 | 自动预约提交了一个预约（仅在开启自动预约时） |

### 3. 自动检查
- 勾选 **按时间间隔自动检查**。
- **检查间隔**：建议 10 分钟以上。每轮会在你设定的值附近随机浮动（默认 ±30%）。
- **登录信息**：填写预约网站的邮箱、密码和**所有**安全问题（每行一个，格式 `问题 | 答案`）。网站登录时会从你设过的问题里随机问两个，所以要全部填上，问题文字请从网站上原样复制。不填也可以，被登出时检查会停下来等你自己登录。
- 其他选项保持默认即可，每一项在设置页都有说明。

设置完点最下面的 **保存设置**。

## 日常使用

- 插件图标的弹窗里能看到当前状态、上次检查时间、下次检查时间，以及范围内的空位和所有可选日期。
- **立即检查**：马上运行一次完整检查。
- **暂停 / 继续**：临时停止所有自动检查。
- **操作记录**：插件做过的每一步，按时间排列，可以筛选、搜索、复制和导出。遇到问题时先看这里。

**保持运行的条件：** Chrome 要一直开着，电脑不能睡眠（屏幕关掉没关系）。Windows 可以在"设置 → 系统 → 电源"里把"插入电源时，使设备进入睡眠状态"设为"从不"；笔记本合盖默认会睡眠，需要另外设置。

## 遇到这些情况，插件会怎么做

| 情况 | 插件的处理 |
|---|---|
| 被登出 | 有保存的登录信息就自动重新登录，否则停下等你登录 |
| 人机验证 | **不会替你点**，暂停检查并弹出提醒，你完成验证后自动继续 |
| 网站排队 | 原地等待，不刷新不点击；超过等待上限（默认 10 分钟）就重新检查 |
| 限流（请求太多） | 同上 |
| 网站维护 | 这一轮结束并推送"正在维护"，按正常间隔继续尝试 |
| 访问受限 / 封禁 | **立即关闭自动检查**，不再重试。请过一段时间（建议至少一两天）再到设置里重新打开 |
| 检查 5 分钟还没结果 | 推送"检查失败"，说明可能卡在哪里 |

## 常见问题

**手机收不到推送？**
1. 先在设置页点"发送测试推送"。收不到的话，检查手机上订阅的主题名和插件里填的是否完全一致，以及手机是否允许 ntfy 发通知。
2. 测试推送能收到、检查结果收不到：打开 **操作记录**，看最后几条卡在哪一步。

**一直显示"需要人机验证"？**
去预约网站的标签页手动完成验证即可，插件会自动继续。如果频繁出现，把检查间隔调长。

**出现"预约网站拒绝访问"？**
自动检查已经自动关闭了。先不要访问网站一段时间，之后再到设置里重新勾选"按时间间隔自动检查"并保存。

**安全问题总是答不上？**
看操作记录里"没有保存答案"后面的问题原文，把它**一字不差**地复制到设置里。

**会不会影响我在网站上正常操作？**
默认情况下，自动检查会刷新预约网站的标签页，可能打断你正在做的操作。自己操作网站时可以先点"暂停"，或者在设置里取消"我正在使用预约网站标签页时也照常检查"。

## 隐私

- 所有设置、登录信息和记录都只保存在你自己的浏览器里，插件不会上传到任何服务器。
- 唯一对外发送的数据是推送到 ntfy.sh 的检查结果文字（日期、状态），不包含账号、密码或个人信息。
